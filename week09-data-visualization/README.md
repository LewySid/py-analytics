# Week 9: Data Visualization with Matplotlib

Charts and a dashboard for a fictional electronics retailer, TechTrends.

## What's inside
- **Sales trends:** monthly, quarterly, and cumulative sales for 2023 vs 2024
- **Product performance:** revenue by category, marketing spend vs sales, revenue share pie chart
- **Customer segments:** purchase amount histogram, spending by age group, purchase frequency by segment
- **Market dashboard:** 2x2 grid comparing TechTrends to its competitors

## Tools
Python, pandas, NumPy, Matplotlib

## How to run
Put these CSVs in the same folder as the notebook, then run all cells:
`sales-data.csv`, `product-performance.csv`, `customer-data.csv`, `competitor-analysis.csv`
