# Week 11: Predicting Customer Lifetime Value with Multiple Regression

A linear regression model that predicts customer lifetime value (CLV) from purchase value, purchase frequency, and tenure.

## What's inside
- Generates a sample dataset of 500 customers
- Splits the data 75/25 into training and test sets
- Trains a linear regression model and checks its coefficients
- Predicts CLV for a new customer

## Key results
- R² = 0.58 on the test set
- RMSE = about $254
- Each extra purchase per year adds about $75 to predicted CLV

## Tools
Python, pandas, NumPy, scikit-learn

## How to run
No data files needed. The notebook creates its own data. Just run all cells.
