# Week 12: Banknote Authentication with Logistic Regression

A logistic regression model that classifies banknotes as genuine or forged.

## What's inside
- Loads the UCI Banknote Authentication dataset (1,372 notes)
- Splits the data 80/20 and scales the features
- Trains a logistic regression model
- Measures accuracy, precision, and recall
- Interprets the model coefficients

## Key results
- Accuracy: 97.1%
- Recall: 100% (caught every forged note in the test set)
- Precision: 93.9%

## Tools
Python, pandas, NumPy, scikit-learn

## How to run
Needs an internet connection. The notebook downloads the dataset from the UCI Machine Learning Repository. Just run all cells.
