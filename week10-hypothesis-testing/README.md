# Week 10: Hypothesis Testing

Using t-tests to check if differences in sales and product data are real or just noise.

## What's inside
- **One-sample t-test:** 2024 monthly sales vs a $650K benchmark
- **Two-sample t-test:** 2023 vs 2024 monthly sales
- **One-sample t-test:** product profit margins vs a 30% benchmark
- **Two-sample t-test:** ROI for high-revenue vs low-revenue categories

## Key results
- 2024 sales were not significantly different from $650K (p = 0.65)
- 2023 vs 2024 sales difference was not significant (p = 0.29)
- Profit margins were not significantly different from 30% (p = 0.76)
- High-revenue categories had significantly higher ROI (p = 0.001)

## Tools
Python, pandas, NumPy, SciPy

## How to run
Put `sales-data.csv` and `product-performance.csv` in the same folder as the notebook, then run all cells.
